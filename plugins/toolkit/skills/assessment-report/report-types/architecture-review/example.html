Executive Summary

Beacon is a well-built platform with two soft pillars. Security and Sustainability already score in the B band and data is durable, but the review found 18 risk items — one critical and eight high — concentrated in Operational Excellence (no runbooks, ~40% outside IaC) and Reliability (a single region with recovery that has never been tested). The theme is not "fragile" — it is "scales well, recovers poorly, runs unhardened operationally." The ≈ 11-day backlog is partly self-funding: the Cost work pays for roughly a third of it.

System Context & Architecture

Beacon is a multi-tenant IoT telemetry platform. A fleet of ~40k devices publishes over MQTT into IoT Core, which fans out to a Kinesis stream; a Lambda parser writes hot records to DynamoDB and raw batches to an S3 data lake. Tenants read through API Gateway → an ECS Fargate API that queries DynamoDB, rendered in a React SPA; Cognito handles per-tenant auth. Everything lives in a single region (eu-west-1).

Data flows left→right: devices → IoT Core → Kinesis → Lambda → DynamoDB (hot) + S3 (lake); tenants read via API Gateway → Fargate API → React SPA, with Cognito auth. Red labels mark risk hotspots detailed in the pillar sections.
Elastic ingest spine

IoT Core → Kinesis → Lambda is pay-per-use and scales to spikes — but the Lambda tier owns both parsing and fan-out, so a poison-pill record can stall a shard and back up ingest.

Two-speed storage

DynamoDB serves hot per-tenant reads; S3 is the analytical lake. Retention rules never tier old telemetry out of hot storage — a cost and sustainability drag that grows with time.

One region

Every component lives in eu-west-1. Managed services give cross-AZ durability, but there is no cross-region failover — a regional event is a full outage with an undefined recovery time.

Beacon is elastic where it ingests and brittle where it recovers — it scales to millions of messages but cannot yet survive the loss of its one region.

Pillar weighting is a business call: a regulated workload would lift Security & Reliability first.
Eleven engineering-days buy Beacon a survivable platform — and the Cost pillar pays for a third of them. The asymmetry, not the effort, is the headline.
